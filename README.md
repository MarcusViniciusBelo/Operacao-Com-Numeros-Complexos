# Operacao-Com-Numeros-Complexos
Programa em Python para Conversão, Adição, Subtração, Multiplicação e Divisão de Números Complexos

As seguintes operações foram implementadas:

- Adição: Dois números complexos são somados em seu formato retangular:

        z1 + z2 = (a + bi) + (c + di) = (a + c) + (b + d)i

- Subtração: Dois números complexos são subtraidos em seu formato retangular:

        z1 - z2 = (a + bi) - (c + di) = (a - c) + (b - d)i

- Multiplicação: Dois números complexos são multiplicados em seu formato polar:

        z1*z2 = (p1∠θ1)*(p2∠θ2) = (p1*p2)∠(θ1 + θ2)

- Divisão: Dois números complexos são divididos em seu formato polar:

        z1/z2 = (p1∠θ1)/(p2∠θ2) = (p1/p2)∠(θ1 - θ2)

A conversão entre retangular e polar e feita a partir das relações trigonométricas:

        p² = a² + b²
        tg(θ) = b/a
